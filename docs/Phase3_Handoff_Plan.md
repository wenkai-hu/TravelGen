## 二、Phase 3 Benchmark 设计（Week3，目标：确定最终模型）

### 2.1 赛题统一 Prompt（所有对比实验的主干）

> 请生成一段杭州西湖一分钟宣传视频。

- **实验1 文案**：以此 Prompt 输入 6 家 LLM，产出 60s 宣传文案（旁白稿）。
- **实验2 分镜**：以实验1最优文案 + 统一分镜 Prompt 输入 LLM，产出结构化分镜。
- **实验3 视频**：以实验2 的镜头级 Prompt 输入各视频模型，产出片段。

### 2.2 实验1：文案生成对比（A负责）

- **模型**：GPT / Claude / Qwen / Gemini / DeepSeek / Kimi（6家，使用 2026 当前版本）
- **方法**：统一 Prompt，每模型生成 3 次取代表性输出；固定 temperature（建议 0.7）
- **评分维度**（1-5分，LLM-Judge 3票 + 人工复核）：

| 维度 | 说明 | 对应赛题 |
|---|---|---|
| 传播感染力 | 开头抓人、节奏起伏、金句记忆点 | 文案质量（30%） |
| 信息准确性 | 西湖地标/典故/数据是否真实（对照RAG知识库） | 真实性要求 |
| 风格符合度 | 是否符合指定风格（如"大气宣传片"） | 风格一致性 |
| 长度控制 | 1分钟≈250-300字旁白 | 时长要求 |
| 脚本可执行性 | 能否直接转换为镜头级脚本/分镜 | 流水线衔接 |

- **输出**：experiments/01_copywriting/ 下每模型一个 md + 评分表

### 2.3 实验2：分镜生成对比（A负责）

- **统一分镜 Prompt**：基于 Phase 1 调研设计（结构见附录A），比较各家 LLM 的分镜能力
- **评分维度**：

| 维度 | 说明 | 调研依据 |
|---|---|---|
| 镜头质量 | 景别/运镜/构图描述的专业性与美感 | Phase 1: FilmAgent 预置镜头库 |
| 镜头逻辑 | 场景切换叙事连贯、起承转合 | Phase 1: 叙事规划综述（层级大纲） |
| 画面一致性 | 跨镜头西湖/雷峰塔等地标与主体描述一致 | Phase 1: Story2Board/StoryDiffusion |
| 结构化程度 | 是否输出规范 JSON（scene→shot 两级） | Phase 1: VideoDirectorGPT 模板 |
| 可执行性 | 镜头Prompt 能否直接被 T2I/T2V 使用 | 流水线衔接 |

- **基线对照**：A自研分镜 Prompt 模板 vs 各家 LLM 默认输出

### 2.4 实验3：视频生成对比（B主导接入，A协助评测）

- **模型**：Runway / Wan2.2（本地或API）/ 可灵 / Veo / MiniMax（+ 视账号情况加 Seedance 2.0、混元）
- **统一输入**：实验2 的镜头级 Prompt（同一组镜头，各模型各生成 1 条）
- **评分维度**：

| 维度 | 说明 | 谁评 |
|---|---|---|
| 画质 | 分辨率、细节、色彩 | A（技术）+ B（观感） |
| 一致性 | 主体/场景/地标是否一致 | A |
| 速度 | 生成耗时（从提交到完成） | B |
| 成本 | 元/条（A的GitHub调研已有价格基线，B核对实际扣费） | B |
| 中文适配 | 中文prompt理解、视频内中文文字 | A |

### 2.5 实验4（可选，为Phase 5铺路）：配音对比

- CosyVoice2 vs GPT-SoVITS vs EdgeTTS：同一旁白稿，比较中文自然度/音色/速度
- 音乐：BGM 候选曲库整理（或 API 推荐），B配合

### 3.2 协作机制（防止踩坑）

1. **共享目录结构**（本周内建好）：
   ```
   experiments/
   ├── prompts/            # 统一Prompt模板（含版本号，LLM版本会迭代）
   ├── 01_copywriting/     # 文案实验
   ├── 02_storyboard/      # 分镜实验
   ├── 03_video/           # 视频实验
   └── 04_voice/           # 配音实验（可选）
   ```
2. **实验日志约定**：每次实验记录 日期/模型版本/Prompt版本/参数(temperature等)/实际成本/结果文件链接——LLM 与视频模型版本迭代很快（如 DeepSeek、Seedance 2.5 即将上线），**不记版本的结果无法复现**，会直接影响 Phase 7 实验报告可信度。
3. **同一模型多轮生成**：文案/分镜每模型至少 3 次生成，避免单次随机性。
4. **成本红线**：视频实验前 B 先给出各通道单条成本预估单，AB确认预算后开跑；建议每模型先跑 1 条"样片"再批量。
5. **同步节奏**：Phase 3 期间每周 1 次短会（周一 15min）：对进度、锁Prompt版本；周中在群/文档留言同步异常。
6. **选型决策规则**：以"评分×成本"矩阵做最终决策（如 Seedance 2.0 vs 可灵 3.0 vs Wan2.2：画质得分接近时选成本低者；本地通道胜出则优先选，因为可持续批量）。

## 附录A：Phase 3 统一 Prompt 模板（A已起草，定稿在 D1）

### A1. 文案 Prompt（实验1）

```
你是一位浙江文旅宣传片资深编导。请为【杭州西湖】撰写一段【1分钟】宣传视频的旁白文案。

要求：
1. 开头3秒抓人，结尾有记忆点金句；全篇情绪有起伏（引入-展开-高潮-收尾）
2. 必须融入真实文旅信息（可在下方知识库资料中取材，禁止编造数据/典故）
3. 风格：【大气唯美】；目标人群：【18-35岁年轻游客】
4. 输出格式：分4段，每段标注起止秒数（0-15s/15-30s/30-45s/45-60s），全文250-300字
5. 同时输出：2个备选标题（用于封面）+ 3个传播话题标签

【知识库资料】
{此处注入RAG检索到的西湖地标/典故/节庆资料，第一轮可用人工整理版本}
```

### A2. 分镜 Prompt（实验2）

```
你是一位电影分镜师。请将以下宣传片文案拆分为分镜表，输出严格JSON（不要其他文字）：
{文案}

JSON结构（scene→shot两级）：
{
  "theme": "杭州西湖宣传片",
  "scenes": [
    {
      "scene_id": 1, "location": "西湖湖面", "time": "清晨",
      "shot_list": [
        {
          "shot_id": 1, "duration_s": 5,
          "camera": {"type": "航拍", "movement": "推进", "angle": "俯拍"},
          "shot_size": "大远景",
          "subject": "西湖+苏堤全貌", "background": "朝霞",
          "prompt": "航拍镜头缓缓推进，西湖苏堤在晨雾中，朝霞映红水面，写实电影质感"
        }
      ]
    }
  ]
}
景别枚举：大远景/全景/中景/近景/特写；运镜枚举：固定/推/拉/摇/移/跟/升降/环绕。
要求：镜头数量6-8个、总时长≈60s、地标描述保持一致（如雷峰塔样式不变）、每镜头含可直接用于文生图的prompt字段。
```

### A3. 视频模型 Prompt（实验3）

直接使用实验2 输出的各镜头 `prompt` 字段 + 统一后缀：
```
（统一后缀，各模型用）写实电影质感，自然光影，8K细节，稳定构图，无文字水印。
```

### A4. LLM-Judge 评分 Prompt（复用）

```
你是文旅视频评审专家。请对以下候选输出按维度1-5打分并给出50字内理由：
维度：{维度列表}
候选输出：{候选}
```

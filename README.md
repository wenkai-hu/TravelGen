# TravelGen · AI 文旅短视频创作平台

**从城市与景点信息出发，将实景参考、文案、分镜、音视频生成和后期合成串联为完整的创作流程。**

TravelGen 是面向城市形象宣传、景区推荐、节庆推广和非遗传播等场景的全栈 AIGC 平台。用户填写城市、地点、主题及视频风格后，可以逐步确认参考图片、修改旁白与分镜、选择音色和配乐，最终生成可预览、下载和继续编辑的短视频。

项目以浙江文旅为主要应用场景，将大模型能力与可编辑的工作流、异步任务管理、数据库持久化及音视频处理结合，让一次视频创作的过程和产物都能被保存与复用。

**关键词：全栈开发 · 多模态 AI · 视觉检索增强 · 异步任务 · 音视频工程**

## 平台功能

| 功能 | 使用体验 |
| --- | --- |
| 创作工作台 | 配置城市、景点、主题、目标受众、视觉风格、时长与画幅，支持横屏、竖屏和方形视频。 |
| 实景参考图 | 按城市与景点检索图片，也可上传自己的素材；用户确认后进行视觉分析，为后续生成提供参考。 |
| 文案与分镜 | 生成创作方案、旁白及结构化分镜，支持修改镜头画面、时长、旁白和参考图。 |
| 镜头生成 | 每张参考图对应一个镜头，支持单镜头重生成；超长镜头分段续写，并在各片段中使用统一参考音色。 |
| 音色与配乐 | 试听预设音色，按描述生成自定义音色；选择背景音乐，或请求 AI 提供选曲方向。 |
| 成片与混音 | 自动拼接视频，保留原生旁白与环境声；可输出原声版和配乐版，并单独调整两类音轨的音量。 |
| 项目与素材管理 | 搜索、筛选、重命名项目，恢复草稿与创作进度；查看视频版本、下载素材，并跨项目复用自定义音色。 |

## 创作流程

```mermaid
flowchart LR
    A[填写创作需求] --> B[检索或上传实景图片]
    B --> C[确认参考图与视觉分析]
    C --> D[生成并确认文案]
    D --> E[生成并编辑分镜]
    E --> F[确认音色与配乐]
    F --> G[逐镜头生成音视频]
    G --> H[自动合成与混音]
    H --> I[预览、下载与素材复用]
```

例如，输入“杭州 · 西湖 · 青年游客 · 文艺清新 · 竖屏短视频”，即可围绕确认的实景图片组织文案与镜头，再选择统一音色和背景音乐完成创作。用户可以在关键阶段修改内容，也可以在成片后调整混音。

## 技术架构

采用前后端分离架构，由后端统一组织模型调用、生成任务、素材存储与视频合成。

| 层次 | 技术与职责 |
| --- | --- |
| 前端交互 | Vue 3、Vue Router、Vite、Naive UI；实现创作工作台、分镜编辑、草稿保存、任务进度和素材浏览。 |
| 后端服务 | Python、FastAPI、Pydantic、Uvicorn；提供 REST API、参数校验、登录认证和工作流状态管理。 |
| 数据持久化 | MySQL、SQLAlchemy、aiomysql；保存用户、项目、任务、素材和音色记录。 |
| 检索与视觉理解 | 百度千帆图片搜索、VLM、Pillow；完成实景检索、图片校验、缓存和景点视觉档案构建。 |
| 文案与知识增强 | 可配置的 LLM 接口、本地文旅知识库、视觉参考约束；组织方案、旁白与结构化分镜。 |
| 音视频生成 | Seedance；结合参考图、参考音色和镜头描述生成原生音视频。 |
| 后期处理 | FFmpeg、imageio-ffmpeg；完成音频提取、格式归一化、片段拼接、配乐处理与重新混音。 |

模型角色通过配置文件管理，文案、视频、视觉理解和图片搜索使用各自的 provider 配置，便于调整模型及服务接口。

## 工程亮点

### 实景与知识共同约束生成

确认后的参考图片会被缓存，并记录内容哈希、来源和视觉分析结果。系统将图片中的可见元素、建筑特征及不确定信息整理成视觉档案，与文旅知识库检索结果一起提供给文案和分镜生成环节，使生成内容更贴近用户选定的地点与画面。

### 可编辑的分阶段工作流

将创作拆成需求、参考图、文案、分镜、音色和成片等阶段，并校验阶段之间的依赖。用户修改镜头、音色或配乐后，系统按影响范围使对应生成结果失效；单镜头重生成与最终混音分别提供独立入口，方便局部调整。

### 异步任务与进度恢复

生成请求返回任务 ID，前端轮询任务状态与结果。图片分析采用受限并发，外部模型请求统一经过 HTTP 传输层。任务与成功产物保存到数据库；关闭页面后可重新查看进度，服务重启时将未完成任务标记为中断，并保留已完成素材供用户继续处理。

### 音视频生成与后期混音分开处理

所有镜头使用同一份确认的参考音色，保留模型生成的旁白与环境声，背景音乐在最终合成阶段加入。配乐支持循环、裁剪、淡入淡出与响度归一化；成片后的音量调整复用已有视频和音轨，无需重新调用视频生成模型。

### 项目存档与素材复用

前端通过本地缓存和防抖同步保存草稿，后端保存完整项目状态。项目、任务、素材与音色建立关联，成功输出通过唯一约束避免重复入库；项目删除采用软删除，已生成素材和被其他项目引用的音色可以保留。

### 模型评测与选型记录

仓库包含文案、分镜等环节的统一 Prompt、模型输出和评测脚本，使用多维评分及交换位置的成对比较辅助模型选型。实验设计、结果和局限记录在文档中，便于复现与后续调整。

## 本地运行

<details>
<summary>展开查看环境配置与启动步骤（PowerShell）</summary>

准备 Python 3.10+、Node.js 20+ 和 MySQL 8.x。在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
if (-not (Test-Path experiments/config.json)) {
    Copy-Item experiments/config_example.json experiments/config.json
}
```

编辑本地 `experiments/config.json`，设置 `db.async_url`，并按示例填写文案、视频、视觉理解和图片搜索服务的配置。上述命令会保留已有的配置文件。

在 MySQL 中创建数据库，并为连接账号授予相应权限：

```sql
CREATE DATABASE IF NOT EXISTS travelgen CHARACTER SET utf8mb4;
```

后端启动时自动创建缺少的数据表。完整生成流程需要配置可用的模型与检索服务。

在一个终端启动后端：

```powershell
cd backend
..\.venv\Scripts\python.exe app.py
```

在另一个终端中，从项目根目录启动前端：

```powershell
cd front
npm install
npm run dev
```

- 前端页面：<http://127.0.0.1:5173>
- 后端接口文档：<http://127.0.0.1:8000/docs>

本地配置文件已加入 `.gitignore`。详细接口与运行说明见 [后端说明](backend/README.md)。

</details>
